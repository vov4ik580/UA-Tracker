# 🇺🇦 UA Tracker

Локальний дашборд «все в одному» для щоденного життя в Україні: погода, повітряні тривоги, графіки відключень світла, новини, курс валют, якість повітря та сонячний день.

Проєкт працює **без API-ключів** і **без npm-залежностей** — потрібен лише Node.js 18+.

## Що всередині

| Блок | Що показує | Джерело |
| --- | --- | --- |
| 🌤 **Погода** | Поточна погода, відчутна температура, вітер, тиск, вологість, графік температури й опадів на 24 год, прогноз на 7 днів для **463 міст України**, згрупованих за областями | [Open-Meteo](https://open-meteo.com/) — безкоштовно, без ключа |

| ⚡ **Відключення** | Графік на сьогодні/завтра для 18 регіонів, вибір черги, таймлайн по 30 хвилин, статистика, наступне відключення | [UA-power-outages-monitor](https://github.com/chaichuk/UA-power-outages-monitor) (формат svitlo) |
| 📰 **Новини** | Стрічка з 6 українських медіа, фільтри за джерелом, час публікації | RSS: Українська правда, Укрінформ, ТСН, УНІАН, Економічна правда, NV |
| 💱 **Курс валют** | Офіційний курс НБУ + конвертер у гривню | [НБУ](https://bank.gov.ua/) — відкриті дані |
| 🌬 **Повітря** | European AQI, PM2.5, PM10 з кольоровою шкалою | Open-Meteo Air Quality |
| ☀️ **Сонце** | Схід, захід, тривалість дня та позиція сонця на дузі | Open-Meteo |

### Дизайн та UX

- Темна тема з українськими акцентами (синій / жовтий), скломорфізм, живі градієнти.
- Адаптивна сітка: десктоп → планшет → телефон.
- Автооновлення: тривоги — 45 с, погода — 10 хв, відключення — 5 хв, новини — 4 хв, валюти — 1 год.
- Збереження вибору міста, області та черги в `localStorage`.
- Стани завантаження (skeleton), помилки з кнопкою повтору, «застарілі» дані з кешу, якщо джерело впало.
- Поважає `prefers-reduced-motion`.

## Запуск

### Варіант 1 — подвійний клік

Відкрийте `Запуск.bat` — сервер стартує і браузер відкриється автоматично.

### Варіант 2 — термінал

```bash
cd UA-Tracker
npm start
```

Потім відкрийте <http://127.0.0.1:4173>.

Якщо порт зайнятий:

```bash
set PORT=5000 && npm start        # Windows (cmd)
$env:PORT=5000; npm start         # Windows (PowerShell)
PORT=5000 npm start               # macOS / Linux
```

## API, які використовуються

| Endpoint | Призначення |
| --- | --- |
| `GET /api/weather?lat=50.45&lon=30.52` | Прогноз Open-Meteo + якість повітря |
| `GET /api/alerts` | Live-статуси тривог (24 області + Київ + Крим) |
| `GET /api/outages?region=kyiv` | Графік відключень для області |
| `GET /api/news` | Агрегована стрічка RSS |
| `GET /api/currency` | Курси валют НБУ |
| `GET /api/health` | Перевірка сервера |

Кеш: тривоги 45 с, погода 10 хв, відключення 5 хв, новини 4 хв, валюти 1 год. Якщо джерело тимчасово недоступне — повертаються останні успішні дані.

## Важливо

- Це **неофіційний** проєкт для особистого використання.
- Дані про тривоги та відключення можуть затримуватись або бути неповними. **Не використовуйте дашборд для критичних рішень** — завжди перевіряйте офіційні джерела (Повітряна тривога, ДТЕК/обленерго).
- Графіки відключень надає сторонній агрегатор. Якщо джерело недоступне, застосунок показує демонстраційні дані з відповідним червоним бейджем.
- Новинні заголовки належать відповідним медіа; посилання ведуть на оригінальні публікації.
